PixelVM — pixel-program virtual machine

Upload a program image (PNG/PPM) and run it directly in your browser.

Spec: 1 pixel = 1 instruction, row-major. PUSHI etc. use the next pixel for a 24-bit signed immediate (two's complement in RGB).
