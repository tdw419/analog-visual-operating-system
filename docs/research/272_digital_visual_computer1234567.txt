## Strategic Assessment of Digital-First Approach

The digital-first strategy is sound engineering practice and will provide important benefits. However, there are some architectural concerns to consider:

**Valid Benefits:**
- Deterministic debugging environment
- Parallel development capability  
- Clear interface boundaries via HAL pattern

**Potential Issues:**
- Risk of building abstractions before fully understanding the analog constraints
- Digital simulations may not capture critical real-world edge cases
- The Bridge pattern implementation could become over-engineered if you don't validate it against actual hardware early

## Critical Analysis of Visual Python Concept

The core Visual Python idea (code→pixels→decode→execute→pixels) presents significant technical challenges that need addressing:

**Major Concerns:**

1. **Reliability Fragility**: Pixel-based code representation is inherently brittle. A single corrupted pixel could break entire code blocks. Your grid font helps, but this remains a fundamental vulnerability.

2. **Security Model**: Executing decoded pixel data creates substantial attack vectors, even with sandboxing. The execution environment needs much more robust isolation than described.

3. **Performance Bottlenecks**: The decode step adds latency to every execution cycle. For real-time applications, this could become prohibitive.

4. **Error Propagation**: Visual artifacts in the decode step could cascade into execution failures, creating complex debugging scenarios.

## Alternative Architecture Consideration

Rather than pure pixel-to-execution coupling, consider a hybrid approach:
- Use pixels as a *display format* for code that's stored separately
- Maintain visual representation while avoiding pixel-decode execution fragility
- This preserves the visual programming benefits while reducing technical risk

## Missing Critical Elements

Your architecture documentation lacks several important considerations:

1. **Failure Recovery**: How does the system handle cascade failures when visual decoding fails?

2. **Performance Metrics**: You need concrete performance targets and measurement strategies, especially for the decode step.

3. **Security Boundaries**: The sandbox implementation needs more rigorous definition, particularly for pixel-decoded execution.

4. **State Consistency**: How do you maintain program state when visual decode fails?

## Recommendations

1. **Validate Core Assumptions Early**: Build a minimal prototype focused solely on the pixel→code→pixel roundtrip to test feasibility before investing in the full architecture.

2. **Benchmark Performance**: Test your OCR/decode performance under realistic conditions and noise levels before committing to this approach.

3. **Define Failure Modes**: Establish clear protocols for when the fundamental pixel decode fails - you need graceful degradation paths.

4. **Consider Incremental Implementation**: Start with pixels for visualization and metadata for execution, then gradually move toward pure pixel-based execution if the approach proves viable.

Your architectural thinking demonstrates solid software engineering principles, and the modular design is well-structured. However, the ambitious coupling of visual representation with code execution represents the highest-risk component of your system. #!/usr/bin/env python3
```python
# visual_python_panes.py — Visual Python MVP (live edit → pixels → decode → exec → pixels)

from __future__ import annotations

import json
import math
import os
import time
from dataclasses import dataclass, field
from typing import Dict, List, Tuple

# Third-party
from PIL import Image

# Local deps you already have
from py2px import Px
from control_strip import draw_control, read_control
from visual_codec import draw_text, sample_text, CELL_W, CELL_H, COLS, ROWS

# Optional: keyboard input (for live mode)
import tkinter as tk


# ----- Configuration ---------------------------------------------------------

# Screen and layout
W, H = 640, 360
GAP = 8
CTRL_H = 24
PANE_W = (W - GAP * 3) // 2
PANE_H = (H - CTRL_H - GAP * 3) // 2

# Pane anchors (top-left corners)
AX, AY = GAP, CTRL_H + GAP                    # Pane A: Source (truth, editable)
BX, BY = AX + PANE_W + GAP, AY                # Pane B: Pixelated (decoded)
CX, CY = AX, AY + PANE_H + GAP                # Pane C: Result (pixels)
DX, DY = BX, BY + PANE_H + GAP                # Pane D: Decode Heatmap

# Behavior
PIXEL_READ = True       # Decode from pixels each tick (True for MVP)
LOG_DIR = "out_vpy_mvp" # Frame PNGs + logs (if using Px out_dir) will land here


# ----- State ----------------------------------------------------------------

@dataclass
class VPState:
    pc: int = 0
    source_lines: List[str] = field(default_factory=lambda: ["1+2"])
    caret: Tuple[int, int] = (0, 0)  # (row, col) in Source pane
    last_result: str = ""            # Rendered to Pane C

    # Internal helpers (not persisted)
    def current_line(self) -> str:
        return self.source_lines[0] if self.source_lines else ""

    def set_current_line(self, new_text: str) -> None:
        if self.source_lines:
            self.source_lines[0] = new_text[:COLS]
        else:
            self.source_lines = [new_text[:COLS]]


# ----- Safe execution --------------------------------------------------------

def safe_eval(expr: str) -> str:
    """
    Evaluate expr in a constrained environment.
    - Whitelist a minimal set of safe helpers.
    - No builtins.
    - Keep it simple for MVP (arithmetic, math, simple aggregations).
    """
    allowed = {
        "math": math,
        "range": range,
        "sum": sum,
        "len": len,
        "min": min,
        "max": max,
        "abs": abs,
        "pow": pow,
    }
    try:
        # NOTE: If you want tighter control, consider AST parsing to whitelist nodes.
        val = eval(expr, {"__builtins__": {}}, allowed)
        return str(val)[:COLS]
    except Exception as e:
        return f"Err: {str(e)[:COLS]}"


# ----- Drawing helpers -------------------------------------------------------

def draw_text_block(px: Px, x: int, y: int, lines: List[str], fg="#FFFFFF", bg="#1A1F2B") -> None:
    for r, line in enumerate(lines[:ROWS]):
        draw_text(px._draw, x, y + r * CELL_H, line.ljust(COLS)[:COLS], fg, bg)

def draw_caret(px: Px, x: int, y: int, caret: Tuple[int, int]) -> None:
    cr, cc = caret
    cx, cy = x + cc * CELL_W, y + cr * CELL_H
    px.rect(cx, cy + CELL_H - 2, CELL_W, 2, "#00FF00")

def draw_labels(px: Px) -> None:
    px.text(AX, AY - 12, "A: Source (edit)", 12, "#A0FFA0")
    px.text(BX, BY - 12, "B: Pixelated (decoded)", 12, "#9BB4FF")
    px.text(CX, CY - 12, "C: Result", 12, "#FFD966")
    px.text(DX, DY - 12, "D: Decode Heatmap", 12, "#FF8080")

def draw_heatmap(px: Px, truth: List[str], decoded: List[str]) -> None:
    # Green cell = match, red = mismatch
    for r in range(ROWS):
        t = (truth[r] if r < len(truth) else "").ljust(COLS)
        d = (decoded[r] if r < len(decoded) else "").ljust(COLS)
        for c in range(COLS):
            cx, cy = DX + c * CELL_W, DY + r * CELL_H
            color = "#002200" if t[c] == d[c] else "#220000"
            px.rect(cx, cy, CELL_W, CELL_H, color)


# ----- Frame lifecycle -------------------------------------------------------

def draw_frame(px: Px, st: VPState) -> None:
    # Background
    px.clear("#0E0F14")

    # Panes
    draw_labels(px)

    # A: Source (truth)
    draw_text_block(px, AX, AY, st.source_lines, fg="#FFFFFF", bg="#1A1F2B")
    draw_caret(px, AX, AY, st.caret)

    # B: Pixelated (this is what we decode)
    draw_text_block(px, BX, BY, st.source_lines, fg="#FFFFFF", bg="#1E2330")

    # C: Result
    result_fg = "#FFD966" if not st.last_result.startswith("Err:") else "#FF8080"
    draw_text_block(px, CX, CY, [st.last_result], fg=result_fg, bg="#1A1F2B")

    # Control strip (CRC is computed inside draw_control)
    draw_control(px._draw, {
        "SCREEN_ID": 100,
        "PC": st.pc & 0xFFF,
        "MAILBOX_IN": 0,
        "MAILBOX_OUT": 0,
    })


def decode_feedback(px: Px, st: VPState) -> Dict:
    """
    Read back what we drew:
    - Control strip (sanity)
    - Pixelated source (from Pane B)
    """
    img = px._img
    ctrl = read_control(img)
    decoded_lines = []
    # MVP: single-line decode for the code row
    decoded_lines.append(sample_text(img, BX, BY).rstrip())
    ctrl["code"] = "\n".join(decoded_lines)
    ctrl["_decoded_lines"] = decoded_lines
    return ctrl


def update_state(st: VPState, ctrl: Dict) -> VPState:
    code = (ctrl.get("code") or "").strip()
    result = safe_eval(code) if code else ""
    return VPState(
        pc=st.pc + 1,
        source_lines=st.source_lines,
        caret=st.caret,
        last_result=result
    )


# ----- Logging (optional) ----------------------------------------------------

def log_frame_json(st: VPState, ctrl: Dict, frame_idx: int) -> None:
    os.makedirs(LOG_DIR, exist_ok=True)
    payload = {
        "frame": frame_idx,
        "pc": st.pc,
        "source": st.source_lines,
        "decoded": ctrl.get("code", ""),
        "result": st.last_result,
        "crc_ok": ctrl.get("_crc_ok", False),
    }
    with open(os.path.join(LOG_DIR, f"log_{frame_idx:06d}.json"), "w") as f:
        json.dump(payload, f, indent=2)


# ----- Keyboard editor -------------------------------------------------------

class Editor:
    """
    Minimal editor for Pane A (single line MVP):
    - Insert printable characters
    - Backspace delete
    - Arrow left/right
    - Enter trims line (acts like "commit" visually)
    """
    def __init__(self, root: tk.Tk, st: VPState) -> None:
        self.root = root
        self.st = st
        self.root.title("Visual Python — Input")
        self.root.geometry("320x80+30+30")
        self.root.attributes("-topmost", True)
        self.root.bind("<Key>", self.on_key)
        # a tiny label hint
        self._hint = tk.Label(root, text="Type here. ESC to clear.", font=("Consolas", 10))
        self._hint.pack(padx=6, pady=6)

    def on_key(self, ev: tk.Event) -> None:
        ch = ev.char or ""
        r, c = self.st.caret
        line = self.st.current_line()

        if ev.keysym == "Escape":
            self.st.set_current_line("")
            self.st.caret = (r, 0)
            return

        if ch.isprintable() and len(line) < COLS:
            self.st.set_current_line(line[:c] + ch + line[c:])
            self.st.caret = (r, min(c + 1, COLS - 1))
        elif ev.keysym == "BackSpace" and c > 0:
            self.st.set_current_line(line[:c - 1] + line[c:])
            self.st.caret = (r, c - 1)
        elif ev.keysym == "Left" and c > 0:
            self.st.caret = (r, c - 1)
        elif ev.keysym == "Right" and c < len(line):
            self.st.caret = (r, c + 1)
        elif ev.keysym in ("Return", "KP_Enter"):
            # Trim to visible width on "commit"
            self.st.set_current_line(line.strip())


# ----- Main loops ------------------------------------------------------------

def run_batch(frames: int = 90, out_dir: str = LOG_DIR) -> None:
    """
    Batch mode:
    - Renders frames to PNGs (via Px out_dir)
    - Logs JSON per frame
    - Performs two code edits at f=40 and f=80 to demonstrate round-trip
    """
    px = Px(W, H, fps=60, out_dir=out_dir)
    st = VPState(source_lines=["1+2"], caret=(0, 0))

    scripted_changes = {
        40: "sum(range(5))",
        80: "(3*7)+4",
    }

    for f in range(frames):

            st.caret = (0, len(st.current_line()))

        draw_frame(px, st)
        px.tick()

        ctrl = decode_feedback(px, st)
        # quick acceptance: ID + CRC
        assert ctrl.get("SCREEN_ID") == 100 and ctrl.get("_crc_ok", False), f"CRC/ID failed: {ctrl}"
        st = update_state(st, ctrl)

        # Decode heatmap (Pane D)
        decoded_lines = ctrl["_decoded_lines"]
        if decoded_lines != st.source_lines[:1]:
            draw_heatmap(px, st.source_lines, decoded_lines)

        log_frame_json(st, ctrl, f)


def run_live(out_dir: str | None = None) -> None:
    """
    Live interactive mode:
    - Captures keyboard input from a small Tk window
    - Renders frames each ~16ms to Px
    - If out_dir is set, frames will be saved too (optional)
    """
    root = tk.Tk()
    px = Px(W, H, fps=60, out_dir=out_dir)
    st = VPState(source_lines=["1+2"], caret=(0, 0))
    editor = Editor(root, st)

    def loop():
        draw_frame(px, st)
        px.tick()

        ctrl = decode_feedback(px, st)
        # We won't assert CRC in live mode, but we can surface mismatch via heatmap
        st2 = update_state(st, ctrl)

        decoded_lines = ctrl["_decoded_lines"]
        if decoded_lines != st.source_lines[:1]:
            draw_heatmap(px, st.source_lines, decoded_lines)

        # advance state
        st.pc = st2.pc
        st.last_result = st2.last_result

        # Next tick
        root.after(16, loop)

    loop()
    root.mainloop()


# ----- Entrypoint ------------------------------------------------------------

if __name__ == "__main__":
    # Choose one:
    # 1) Batch mode: writes frames + logs to ./out_vpy_mvp/
```

```python
#!/usr/bin/env python3
# visual_python_mvp.py — Visual Python MVP with live editing, Tkinter window, AST executor, and Hall of Drift
import sys
import time
import math
import ast
import json
import os
from dataclasses import dataclass, field
from typing import Dict, List
from PIL import Image, ImageDraw, ImageStat, ImageTk
import tkinter as tk
from py2px import Px

# Ensure these files are in the same directory
from control_strip import draw_control, read_control
from visual_codec import draw_text, sample_text, CELL_W, CELL_H, COLS, ROWS

# Configuration
PIXEL_READ = True  # Decode from pixels only
W, H = 640, 360
GAP = 8
CTRL_H = 24
PANE_W = (W - GAP * 3) // 2
PANE_H = (H - CTRL_H - GAP * 3) // 2
FRAME_DIR = "out_vpy_mvp"

@dataclass
class VPState:
    pc: int = 0
    source_lines: List[str] = field(default_factory=lambda: ["1+2"])
    caret: tuple[int, int] = (0, 0)  # (row, col)
    last_result: str = ""

class SafeEvaluator:
    """Safely evaluate Python AST with whitelisted operations."""
    ALLOWED_NODES = {
        ast.Module, ast.Expr, ast.Num, ast.Str, ast.Name, ast.BinOp,
        ast.Add, ast.Sub, ast.Mult, ast.Div, ast.Call, ast.UnaryOp,
        ast.USub, ast.List, ast.Tuple, ast.NameConstant
    }
    ALLOWED_NAMES = {"math", "range", "sum", "len", "min", "max", "abs", "pow"}

    def __init__(self):
        self.globals = {
            "math": math, "range": range, "sum": sum, "len": len,
            "min": min, "max": max, "abs": abs, "pow": pow,
            "__builtins__": {}
        }

    def check_node(self, node):
        """Recursively validate AST nodes."""
        if type(node) not in self.ALLOWED_NODES:
            raise ValueError(f"Unsupported node: {type(node).__name__}")
        if isinstance(node, ast.Name) and node.id not in self.ALLOWED_NAMES:
            raise ValueError(f"Unsupported name: {node.id}")
        for child in ast.walk(node):
            if type(child) not in self.ALLOWED_NODES:
                raise ValueError(f"Unsupported child node: {type(child).__name__}")
        return True

    def eval(self, code: str) -> str:
        """Evaluate code string with AST validation and timeout."""
        import signal
        def timeout_handler(signum, frame):
            raise TimeoutError("Evaluation timed out")
        signal.signal(signal.SIGALRM, timeout_handler)
        signal.alarm(1)  # 1-second timeout
        try:
            tree = ast.parse(code, mode="eval")
            self.check_node(tree)
            result = eval(compile(tree, "<string>", "eval"), self.globals)
            signal.alarm(0)
            return str(result)[:COLS-5]
        except Exception as e:
            signal.alarm(0)
            return f"Err: {str(e)[:COLS-5]}"

def draw_pane(px: Px, x: int, y: int, lines: List[str], color_fg="#FFFFFF", color_bg="#1E2330", caret=None):
    """Draw a text pane with optional caret."""
    for r, line in enumerate(lines[:ROWS]):
        draw_text(px._draw, x, y + r * CELL_H, line.ljust(COLS)[:COLS], color_fg, color_bg)
    if caret:
        cx, cy = x + caret[1] * CELL_W, y + caret[0] * CELL_H
        px.rect(cx, cy + CELL_H - 2, CELL_W, 2, "#00FF00")  # Caret underline

def decode_pane(img: Image.Image, x: int, y: int) -> List[str]:
    """Decode a text pane from pixel data."""
    return [sample_text(img, x, y + r * CELL_H).rstrip() for r in range(ROWS)]

def draw_heatmap(px: Px, x: int, y: int, truth: List[str], decoded: List[str]):
    """Visualize decoding errors as a heatmap."""
    for r in range(ROWS):
        t = (truth[r] if r < len(truth) else "").ljust(COLS)
        d = (decoded[r] if r < len(decoded) else "").ljust(COLS)
        for c in range(COLS):
            cx, cy = x + c * CELL_W, y + r * CELL_H
            color = "#002200" if t[c] == d[c] else "#220000"  # Green for OK, red for mismatch
            px.rect(cx, cy, CELL_W, CELL_H, color)

def draw_frame(px: Px, st: VPState):
    """Draw the entire frame with all panes."""
    px.clear("#0E0F14")
    # Pane coordinates
    ax, ay = GAP, CTRL_H + GAP  # A: Source (editable truth)
    bx, by = ax + PANE_W + GAP, ay  # B: Pixelated Source
    cx, cy = ax, ay + PANE_H + GAP  # C: Result
    dx, dy = bx, cy  # D: Heatmap
    # Labels
    px.text(ax, ay-12, "A: Source (edit)", 12, "#A0FFA0")
    px.text(bx, by-12, "B: Pixelated (decoded)", 12, "#9BB4FF")
    px.text(cx, cy-12, "C: Result", 12, "#FFD966")
    px.text(dx, dy-12, "D: Decode Heatmap", 12, "#FF8080")
    # Draw panes
    draw_pane(px, ax, ay, st.source_lines, color_fg="#FFFFFF", color_bg="#1A1F2B", caret=st.caret)
    draw_pane(px, bx, by, st.source_lines, color_fg="#FFFFFF", color_bg="#1E2330")
    draw_pane(px, cx, cy, [st.last_result], color_fg="#FFD966" if "Err" not in st.last_result else "#FF8080", color_bg="#1A1F2B")
    # Control strip
    draw_control(px._draw, {"SCREEN_ID": 100, "PC": st.pc, "MAILBOX_IN": 0, "MAILBOX_OUT": 0})

def decode(px: Px, st: VPState) -> Dict:
    """Decode the frame (control strip + pixelated code)."""
    img = px._img
    ctrl = read_control(img)
    if not ctrl.get("_crc_ok", False):
        ctrl["err"] = "crc"
    ctrl["code"] = decode_pane(img, bx, by)[0] if PIXEL_READ else st.source_lines[0].strip()
    return ctrl

def update(st: VPState, ctrl: Dict, evaluator: SafeEvaluator) -> VPState:
    """Update state based on decoded frame."""
    code = ctrl.get("code", "").strip()
    result = evaluator.eval(code) if code else ""
    return VPState(pc=st.pc+1, source_lines=st.source_lines, caret=st.caret, last_result=result)

class Editor:
    """Handle live keyboard input."""
    def __init__(self, master, state: VPState):
        self.master = master
        self.state = state
        self.master.bind("<Key>", self.handle_key)

    def handle_key(self, event):
        ch = event.char
        r, c = self.state.caret
        line = self.state.source_lines[r]
        if ch.isprintable() and len(line) < COLS:
            self.state.source_lines[r] = line[:c] + ch + line[c:]
            self.state.caret = (r, min(c+1, COLS-1))
        elif event.keysym == "BackSpace" and c > 0:
            self.state.source_lines[r] = line[:c-1] + line[c:]
            self.state.caret = (r, c-1)
        elif event.keysym == "Left" and c > 0:
            self.state.caret = (r, c-1)
        elif event.keysym == "Right" and c < len(line):
            self.state.caret = (r, c+1)
        elif event.keysym == "Return":
            self.state.source_lines[r] = line[:COLS].strip()

class HallOfDrift:
    """Log and visualize decode failures."""
    def __init__(self, log_dir=FRAME_DIR):
        self.log_dir = log_dir
        os.makedirs(log_dir, exist_ok=True)

    def log_frame(self, st: VPState, ctrl: Dict, frame_idx: int, img: Image.Image):
        """Log frame data and save failure artifacts if needed."""
        log = {
            "frame": frame_idx,
            "pc": st.pc,
            "source": st.source_lines,
            "decoded": ctrl.get("code", ""),
            "result": st.last_result,
            "crc_ok": ctrl.get("_crc_ok", False)
        }
        log_path = f"{self.log_dir}/log_{frame_idx:06d}.json"
        with open(log_path, "w") as f:
            json.dump(log, f, indent=2)
        if ctrl.get("code", "").strip() != st.source_lines[0].strip() or not ctrl.get("_crc_ok", True):
            img.save(f"{self.log_dir}/fail_{frame_idx:06d}.png")
            with open(f"{self.log_dir}/fail_{frame_idx:06d}.json", "w") as f:
                json.dump({"error": "decode or CRC failure", **log}, f, indent=2)

def run_visual_python_mvp(frames=90, out_dir=FRAME_DIR, live=True):
    """Run the Visual Python MVP (batch or live with Tkinter window)."""
    root = tk.Tk()
    if not live:
        root.withdraw()  # Hide window for batch mode
    else:
        canvas = tk.Canvas(root, width=W, height=H, bg="#0E0F14")
        canvas.pack()
        root.title("Visual Python MVP")

    px = Px(W, H, 60, out_dir if frames else None)
    st = VPState(source_lines=["1+2"], caret=(0, 0))
    evaluator = SafeEvaluator()
    editor = Editor(root, st)
    hall = HallOfDrift(out_dir)

    # Pre-programmed code changes for batch mode
    code_changes = {40: "sum(range(5))", 80: "(3*7)+4"}

    if frames:
        for f in range(frames):
            if f in code_changes:
                st.source_lines[0] = code_changes[f]
                st.caret = (0, len(st.source_lines[0]))
            draw_frame(px, st)
            px.tick()
            ctrl = decode(px, st)
            assert ctrl.get("SCREEN_ID") == 100 and ctrl.get("_crc_ok", True), f"Frame {f} failed: {ctrl}"
            if PIXEL_READ and ctrl["code"].strip() != st.source_lines[0].strip():
                draw_heatmap(px, bx, by, st.source_lines, [ctrl["code"]])
            st = update(st, ctrl, evaluator)
            hall.log_frame(st, ctrl, f, px._img)
    else:  # Live interactive loop with Tkinter window
        photo = None
        def loop():
            nonlocal photo
            draw_frame(px, st)
            px.tick()
            ctrl = decode(px, st)
            if PIXEL_READ and ctrl["code"].strip() != st.source_lines[0].strip():
                draw_heatmap(px, bx, by, st.source_lines, [ctrl["code"]])
            st = update(st, ctrl, evaluator)
            hall.log_frame(st, ctrl, st.pc, px._img)
            # Update Tkinter canvas
            photo = ImageTk.PhotoImage(px._img)
            canvas.create_image(0, 0, image=photo, anchor="nw")
            root.after(16, loop)  # ~60Hz
        loop()
        root.mainloop()

if __name__ == "__main__":
    run_visual_python_mvp(frames=90, live=False)  # Batch mode
    # run_visual_python_mvp(frames=0, live=True)  # Uncomment for live mode
```

### 3. AST‑gated executor

```python
import ast

ALLOWED_NODES = {
    ast.Module, ast.Expr, ast.Assign, ast.BinOp, ast.UnaryOp,
    ast.Num, ast.Constant, ast.Name, ast.Load, ast.Store,
    ast.Call, ast.If, ast.For, ast.While, ast.Compare,
    ast.Add, ast.Sub, ast.Mult, ast.Div, ast.Pow, ast.Mod,
    ast.Eq, ast.NotEq, ast.Lt, ast.LtE, ast.Gt, ast.GtE,
    ast.arguments, ast.arg, ast.FunctionDef, ast.Return,
    ast.List, ast.Tuple, ast.Dict, ast.Str, ast.Attribute,
}

SAFE_GLOBALS = {
    "math": math,
    "range": range,
    "sum": sum,
    "len": len,
    "min": min,
    "max": max,
    "abs": abs,
    "pow": pow,
}

def safe_exec_multiline(lines: List[str]) -> str:
    code = "\n".join(lines)
    try:
        tree = ast.parse(code, mode="exec")
    except SyntaxError as e:
        return f"SyntaxErr: {e.msg}"

    for node in ast.walk(tree):
        if type(node) not in ALLOWED_NODES:
            return f"Disallowed: {type(node).__name__}"

    try:
        loc: Dict[str, object] = {}
        exec(compile(tree, "<vpy>", "exec"), {"__builtins__": {}}, {**SAFE_GLOBALS, **loc})
        # If last line is an expression, eval it for display
        try:
            last_expr = ast.parse(lines[-1], mode="eval")
            val = eval(compile(last_expr, "<vpy>", "eval"), {"__builtins__": {}}, {**SAFE_GLOBALS, **loc})
            return str(val)[:COLS]
        except SyntaxError:
            return ""
    except Exception as e:
        return f"Err: {str(e)[:COLS]}"
```
