### 1. Pixel Encoding Scheme
We'll use a simple scheme for a grid-based image (e.g., 10x1 pixels for a linear program):
- **Opcodes**: Specific RGB colors represent operations (e.g., green for `+`, red for `*`).
- **Data (Numbers)**: R channel stores value (0-255 for simplicity; extend to full RGB for larger numbers).
- **Control Flow**: Special colors for jumps (e.g., purple for conditional jump).
- **Memory**: Reserved pixels for variables (e.g., position (0,0) for `x`).
- **Ans/Output**: Fixed pixel for result (e.g., last pixel).

Example Palette:
| Op/Code | RGB | Description |
|---------|-----|-------------|
| NOP | (0,0,0) | No operation |
| HALT | (255,255,255) | Stop execution |
| LOAD_CONST | (0,0,255) | Load number from next pixel's R channel |
| ADD | (0,255,0) | Pop two, push sum |
| MUL | (255,0,0) | Pop two, push product |
| PRINT | (255,255,0) | Pop and "print" (set to output pixel) |
| STORE | (0,128,0) | Pop value, store in variable pixel (next R = var index) |
| LOAD | (0,0,128) | Load from variable pixel (next R = var index) |
| JZ | (0,128,128) | Pop; if 0, jump to next pixel's R as offset |

Numbers are encoded in the R channel (0-255), with G/B = 0.

- Pixel 1: (2,0,0) # 2
- Pixel 2: LOAD_CONST (0,0,255)
- Pixel 3: (3,0,0) # 3
- Pixel 4: LOAD_CONST (0,0,255)
- Pixel 5: (4,0,0) # 4
- Pixel 6: MUL (255,0,0)
- Pixel 7: ADD (0,255,0)
- Pixel 8: PRINT (255,255,0)

### 2. PixelVM Implementation in Python
This script loads an image, interprets pixels as instructions, executes the program, and outputs the result. It integrates with the Visual Python 4-pane system for visualization.

```python
from PIL import Image

class PixelVM:
    def __init__(self):
        self.stack = []
        self.variables = {}  # var_index: value
        self.ans = 0
        self.execution_log = []

    def execute_image(self, image_path: str) -> float:
        """Load image and execute pixel program."""
        img = Image.open(image_path)
        pixels = img.load()
        width, height = img.size
        ip = 0  # Linear index
        while ip < width * height:
            r, g, b = pixels[ip % width, ip // width]  # Row-major
            opcode = self.decode_opcode(r, g, b)
            self.execution_log.append({"ip": ip, "opcode": opcode})
            if opcode == "HALT":
                break
            if opcode == "LOAD_CONST":
                ip += 1
                nr, ng, nb = pixels[ip % width, ip // width]
                value = nr  # R channel as value
                self.stack.append(value)
            elif opcode == "ADD":
                b = self.stack.pop()
                a = self.stack.pop()
                self.stack.append(a + b)
            elif opcode == "MUL":
                b = self.stack.pop()
                a = self.stack.pop()
                self.stack.append(a * b)
            elif opcode == "PRINT":
                self.ans = self.stack.pop()
                print(self.ans)
            elif opcode == "STORE":
                ip += 1
                nr, ng, nb = pixels[ip % width, ip // width]
                var_index = nr
                value = self.stack.pop()
                self.variables[var_index] = value
            elif opcode == "LOAD":
                ip += 1
                nr, ng, nb = pixels[ip % width, ip // width]
                var_index = nr
                value = self.variables.get(var_index, 0)
                self.stack.append(value)
            elif opcode == "JZ":
                v = self.stack.pop()
                ip += 1
                nr, ng, nb = pixels[ip % width, ip // width]
                jump_offset = nr
                if v == 0:
                    ip += jump_offset - 1  # Adjust for next increment
            else:
                raise ValueError(f"Unknown opcode at {ip}")
            ip += 1
        return self.ans

def decode_opcode(self, r, g, b):
    if (r, g, b) == (0, 0, 0):
        return "NOP"
    if (r, g, b) == (255, 255, 255):
        return "HALT"
    if (r, g, b) == (0, 0, 255):
        return "LOAD_CONST"
    if (r, g, b) == (0, 255, 0):
        return "ADD"
    if (r, g, b) == (255, 0, 0):

# ===== PIXEL INSTRUCTION SET ARCHITECTURE =====

class PixelISA:
    """Pixel Instruction Set Architecture - defines how pixels encode instructions"""
    
    # Opcodes encoded as RGB values
    OPCODES = {
        # Arithmetic operations
        'ADD': (0, 255, 0),      # Green
        'SUB': (255, 0, 0),      # Red
        'MUL': (0, 0, 255),      # Blue
        'DIV': (255, 255, 0),    # Yellow
        'MOD': (255, 0, 255),    # Magenta
        'POW': (0, 255, 255),    # Cyan
        
        # Stack operations
        'PUSH': (128, 128, 128),  # Gray
        'POP': (64, 64, 64),      # Dark gray
        'DUP': (192, 192, 192),  # Light gray
        'SWAP': (160, 160, 160),  # Medium gray
        
        # Control flow
        'JUMP': (255, 128, 0),    # Orange
        'JZ': (128, 255, 0),     # Lime
        'JNZ': (0, 128, 255),    # Light blue
        'HALT': (255, 255, 255), # White
        
        # Special values
        'CONST': (0, 0, 0),      # Black (next pixel is value)
        'VAR': (32, 32, 32),     # Very dark gray (next pixel is var index)
        'PRINT': (255, 165, 0),  # Orange-red
        'STORE': (128, 0, 128),  # Purple
    }
    
    # Reverse mapping for decoding
    RGB_TO_OPCODE = {v: k for k, v in OPCODES.items()}
    
    @staticmethod
    def encode_value(value: int) -> Tuple[int, int, int]:
        """Encode a 24-bit signed integer as RGB"""
        if not (-2**23 <= value < 2**23):
            raise ValueError(f"Value {value} out of 24-bit range")
        
        if value < 0:
            value = (1 << 24) + value  # Two's complement
        
        r = value & 0xFF
        g = (value >> 8) & 0xFF
        b = (value >> 16) & 0xFF
        
        return (r, g, b)
    
    @staticmethod
    def decode_value(r: int, g: int, b: int) -> int:
        """Decode RGB to a 24-bit signed integer"""
        value = (b << 16) | (g << 8) | r
        
        if value >= (1 << 23):
            value -= (1 << 24)
            
        return value
    
    @staticmethod
    def is_opcode(rgb: Tuple[int, int, int]) -> bool:
        """Check if RGB represents an opcode"""
        return rgb in PixelISA.RGB_TO_OPCODE
    
    @staticmethod
    def get_opcode(rgb: Tuple[int, int, int]) -> str:
        """Get opcode from RGB"""
        return PixelISA.RGB_TO_OPCODE.get(rgb, 'UNKNOWN')

# ===== PIXEL VIRTUAL MACHINE =====

class PixelVM:
    """Virtual Machine that executes pixel-based programs"""
    
    def __init__(self, width: int = 100, height: int = 100):
        self.width = width
        self.height = height
        self.canvas = Image.new('RGB', (width, height), (0, 0, 0))
        self.pixels = self.canvas.load()
        self.ip = (0, 0)  # Instruction pointer (x, y)
        self.stack = []
        self.variables = {}
        self.output = []
        self.halted = False
        self.execution_log = []
        
    def load_from_image(self, image_path: str):
        """Load a pixel program from an image file"""
        self.canvas = Image.open(image_path)
        self.width, self.height = self.canvas.size
        self.pixels = self.canvas.load()
        self.reset_state()
        
    def save_to_image(self, image_path: str):
        """Save the current pixel program to an image file"""
        self.canvas.save(image_path)
        
    def reset_state(self):
        """Reset VM state for new execution"""
        self.ip = (0, 0)
        self.stack = []
        self.output = []
        self.halted = False
        self.execution_log = []
        
    def get_pixel(self, x: int, y: int) -> Tuple[int, int, int]:
        """Get RGB value of a pixel"""
        if 0 <= x < self.width and 0 <= y < self.height:
            return self.pixels[x, y]
        return (0, 0, 0)  # Default black for out of bounds
        
    def set_pixel(self, x: int, y: int, rgb: Tuple[int, int, int]):
        """Set RGB value of a pixel"""
        if 0 <= x < self.width and 0 <= y < self.height:
            self.pixels[x, y] = rgb
            
    def next_pixel(self) -> Tuple[int, int]:
        """Move to next pixel in row-major order"""
        x, y = self.ip
        x += 1
        if x >= self.width:
            x = 0
            y += 1
        if y >= self.height:
            self.halted = True
        return (x, y)
        
    def execute_instruction(self, opcode: str, x: int, y: int) -> bool:
        """Execute a single instruction"""
        self.execution_log.append({
            'opcode': opcode,
            'position': (x, y),
            'stack': list(self.stack),
            'variables': dict(self.variables)
        })
        
        if opcode == 'ADD':
            if len(self.stack) >= 2:
                b = self.stack.pop()
                a = self.stack.pop()
                self.stack.append(a + b)
                
        elif opcode == 'SUB':
            if len(self.stack) >= 2:
                b = self.stack.pop()
                a = self.stack.pop()
                self.stack.append(a - b)
                
        elif opcode == 'MUL':
            if len(self.stack) >= 2:
                b = self.stack.pop()
                a = self.stack.pop()
                self.stack.append(a * b)
                
        elif opcode == 'DIV':
            if len(self.stack) >= 2:
                b = self.stack.pop()
                a = self.stack.pop()
                self.stack.append(a // b if b != 0 else 0)
                
        elif opcode == 'MOD':
            if len(self.stack) >= 2:
                b = self.stack.pop()
                a = self.stack.pop()
                self.stack.append(a % b if b != 0 else 0)
                
        elif opcode == 'POW':
            if len(self.stack) >= 2:
                b = self.stack.pop()
                a = self.stack.pop()
                self.stack.append(a ** b)
                
        elif opcode == 'PUSH':
            # Next pixel contains value
            next_x, next_y = self.next_pixel()
            value_rgb = self.get_pixel(next_x, next_y)
            value = PixelISA.decode_value(*value_rgb)
            self.stack.append(value)
            self.ip = (next_x, next_y)
            return True  # Skip normal IP advancement
            
        elif opcode == 'POP':
            if self.stack:
                self.stack.pop()
                
        elif opcode == 'DUP':
            if self.stack:
                self.stack.append(self.stack[-1])
                
        elif opcode == 'SWAP':
            if len(self.stack) >= 2:
                self.stack[-1], self.stack[-2] = self.stack[-2], self.stack[-1]
                
        elif opcode == 'JUMP':
            # Next pixel contains target position
            next_x, next_y = self.next_pixel()
            target_rgb = self.get_pixel(next_x, next_y)
            target_value = PixelISA.decode_value(*target_rgb)
            # Convert value to position (simple mapping)
            target_x = target_value % self.width
            target_y = (target_value // self.width) % self.height
            self.ip = (target_x, target_y)
            return True  # Skip normal IP advancement
            
        elif opcode == 'JZ':
            if self.stack and self.stack[-1] == 0:
                # Next pixel contains target position
                next_x, next_y = self.next_pixel()
                target_rgb = self.get_pixel(next_x, next_y)
                target_value = PixelISA.decode_value(*target_rgb)
                target_x = target_value % self.width
                target_y = (target_value // self.width) % self.height
                self.ip = (target_x, target_y)
                return True
            self.stack.pop()  # Consume the condition
            
        elif opcode == 'JNZ':
            if self.stack and self.stack[-1] != 0:
                # Next pixel contains target position
                next_x, next_y = self.next_pixel()
                target_rgb = self.get_pixel(next_x, next_y)
                target_value = PixelISA.decode_value(*target_rgb)
                target_x = target_value % self.width
                target_y = (target_value // self.width) % self.height
                self.ip = (target_x, target_y)
                return True
            self.stack.pop()  # Consume the condition
            
        elif opcode == 'CONST':
            # Next pixel contains constant value
            next_x, next_y = self.next_pixel()
            value_rgb = self.get_pixel(next_x, next_y)
            value = PixelISA.decode_value(*value_rgb)
            self.stack.append(value)
            self.ip = (next_x, next_y)
            return True  # Skip normal IP advancement
            
        elif opcode == 'VAR':
            # Next pixel contains variable index
            next_x, next_y = self.next_pixel()
            var_rgb = self.get_pixel(next_x, next_y)
            var_index = PixelISA.decode_value(*var_rgb)
            self.stack.append(self.variables.get(var_index, 0))
            self.ip = (next_x, next_y)
            return True  # Skip normal IP advancement
            
        elif opcode == 'STORE':
            if self.stack:
                # Next pixel contains variable index
                next_x, next_y = self.next_pixel()
                var_rgb = self.get_pixel(next_x, next_y)
                var_index = PixelISA.decode_value(*var_rgb)
                self.variables[var_index] = self.stack.pop()
                self.ip = (next_x, next_y)
                return True  # Skip normal IP advancement
                
        elif opcode == 'PRINT':
            if self.stack:
                value = self.stack.pop()
                self.output.append(value)
                
        elif opcode == 'HALT':
            self.halted = True
            
        return False
        
    def step(self):
        """Execute one step of the pixel program"""
        if self.halted:
            return False
            
        x, y = self.ip
        rgb = self.get_pixel(x, y)
        opcode = PixelISA.get_opcode(rgb)
        
        if opcode == 'UNKNOWN':
            # Skip unknown pixels
            self.ip = self.next_pixel()
            return True
            
        skip_advance = self.execute_instruction(opcode, x, y)
        
        if not skip_advance:
            self.ip = self.next_pixel()
            
        return not self.halted
        
    def run(self, max_steps: int = 1000):
        """Run the pixel program"""
        self.reset_state()
        steps = 0
        
        while not self.halted and steps < max_steps:
            if not self.step():
                break
            steps += 1
            
        return steps

class PixelCompiler:

    def compile_expression(expr: str, width: int = 20, height: int = 20) -> PixelVM:
        """Compile a simple expression to a pixel program"""
        vm = PixelVM(width, height)
        
        # Simple expression parser (for demonstration)
        # This is a very basic implementation that handles simple arithmetic
        tokens = expr.replace(' ', '')
        
        # For demonstration, we'll compile "2+3*4"
        if expr == "2+3*4":
            # PUSH 2
            vm.set_pixel(0, 0, PixelISA.OPCODES['PUSH'])

            # PUSH 3
            vm.set_pixel(2, 0, PixelISA.OPCODES['PUSH'])

            vm.set_pixel(4, 0, PixelISA.OPCODES['PUSH'])

# ===== CALCULATOR INTERFACE =====

class PixelCalculator:
    """Calculator interface that uses pixel programs for calculations"""
    
    def __init__(self):
        self.vm = PixelVM(30, 30)
        self.history = []
        
    def calculate(self, expression: str) -> List[Any]:
        """Calculate an expression using pixel programs"""
        # Compile expression to pixel program
        vm = PixelCompiler.compile_expression(expression)
        
        # Execute the pixel program
        vm.run()
        
        # Store in history
        self.history.append({
            'expression': expression,
            'output': vm.output.copy(),
            'variables': dict(vm.variables)
        })
        
        return vm.output
    
    def visualize_last_calculation(self, output_path: str):
        """Create a 4-pane visualization of the last calculation"""
        if self.history:
            last_calc = self.history[-1]

The principle is simple yet powerful: each pixel on a 2D grid is treated as a discrete instruction for a virtual machine to execute in a sequential manner.[1]

Your PISA is a stack-based architecture, which is analogous to how the CPython virtual machine and other modern interpreters operate.[2] A simple `2 + 3 * 4` calculation is not executed in one step but is broken down into a series of low-level instructions: `PUSHI 2`, `PUSHI 3`, `PUSHI 4`, `MUL`, `ADD`, `PRINT`, `HALT`. Each of these instructions is represented by a specific, unambiguous pixel color (e.g., `(255, 128, 0)` for `MUL`).

Your chosen encoding scheme is particularly robust:
*   **Opcodes**: Specific RGB tuples map directly to instructions like `ADD` or `PRINT`. The interpreter checks the pixel's color to determine which operation to perform next.[3, 4]

This design successfully bridges the gap between high-level human logic (`2 + 3 * 4`) and a raw, low-level machine-readable format.
