def _pad_to(s: str, n: int) -> str:
    return (s + " " * n)[:n]

def vote3(blocks: list[list[str]], rows: int, cols: int) -> list[str]:
    """Per-cell majority from up to 3 decoded blocks; tie -> newest wins."""
    if not blocks:
        return [""]
    # Right-align lengths
    B = []
    for b in blocks:
        rows_here = max(rows, len(b))
        B.append([_pad_to(b[r] if r < len(b) else "", cols) for r in range(rows_here)])
    rows_final = max(len(b) for b in B)
    out: list[str] = []
    for r in range(rows_final):
        row_chars = []
        for c in range(cols):
            # newest first so ties prefer newest
            cands = [B[k][r][c] if r < len(B[k]) else " " for k in reversed(range(len(B)))]
            # simple majority
            if len(cands) == 1:
                ch = cands[0]
            elif len(cands) == 2:
                ch = cands[0] if cands[0] == cands[1] else cands[0]  # tie->newest
            else:
                ch = (cands[0] if cands[0] == cands[1] or cands[0] == cands[2]
                      else (cands[1] if cands[1] == cands[2] else cands[0]))
            row_chars.append(ch)
        out.append("".join(row_chars).rstrip())
    return out[:rows]

## Using Screen Refresh Rate in Visual Python

The screen refresh rate (e.g., 60Hz, ~16.67ms per frame) acts as a **hardware clock** for the Visual Python loop, providing a natural cadence for the **code → pixels → decode → execute → pixels** cycle. By synchronizing updates to the refresh cycle, you ensure deterministic timing, avoid visual artifacts like tearing, and enable precise state changes. Here’s how to leverage it:

### Key Benefits of Refresh-Driven Updates
1. **Stable Timing**: The refresh rate (60Hz = 16.67ms) provides a consistent tick for the loop, ensuring predictable execution and rendering.
2. **Vblank Synchronization**: Presenting frames during the vertical blank (vblank) interval avoids tearing and ensures the screen displays a complete, coherent frame.
3. **Frame Boundary Detection**: A sequence (`SEQ`) bit in the control strip toggles each frame, allowing the system to detect new frames and avoid double-processing.
4. **State Change Safety**: Updates (e.g., code changes, mailbox messages) are applied only after verifying the previous frame’s integrity (via CRC and heatmap), preventing unstable state propagation.
5. **Analog Readiness**: Synchronizing with the refresh rate mimics how a camera would capture frames, preparing for analog hardware integration.

### How to Use Refresh Updates to Change the Screen
- **Vsync-Driven Loop**: Use the display’s refresh (or a fallback timer) to drive the main loop:
  - **Frame N**: Draw the current state (Pane A: source, Pane B: pixelated source, Pane C: result, Pane D: heatmap, control strip with `SEQ`).
  - **Frame N+1**: Capture the displayed frame, decode it (Pane B + control strip), verify integrity (CRC + heatmap), execute the decoded code, and prepare the next frame’s state.
  - **Change Logic**: Only update the screen’s content (e.g., new code, result, or mailbox message) after a successful decode and verification, ensuring causality (what you see is what you execute).
- **Two-Phase Commit**:
  - **Phase 1 (Draw)**: Render the intended state (e.g., new code in Pane A) with a toggled `SEQ` bit.
  - **Phase 2 (Verify)**: On the next refresh, decode the frame, check CRC and heatmap, and apply state changes (e.g., update `last_result` or process `MAILBOX_OUT`) only if valid.
- **Temporal ECC**: Use a 3-frame ring buffer to perform majority voting on decoded glyphs, reducing errors from transient noise:

  from collections import defaultdict

      if not history: return []

          for frame in history:
              if row < len(frame):
                  for col in range(COLS):

          result.append("".join(max(votes[(row, col)], key=len) for col in range(COLS)))
      return result

@dataclass
class VPState:
    pc: int = 0
    source_lines: List[str] = field(default_factory=lambda: [""])
    caret: Tuple[int, int] = (0, 0)
    last_result: str = ""
    mailbox_out: Dict = field(default_factory=dict)
    seq: int = 0  # Sequence bit for frame sync
    def current_line(self) -> str:
        return self.source_lines[self.caret[0]] if self.source_lines else ""
    def set_current_line(self, new_text: str) -> None:
        r = self.caret[0]
        if r < len(self.source_lines):
            self.source_lines[r] = new_text[:COLS]
        else:
            self.source_lines.append(new_text[:COLS])

class SafeEvaluator:
    ALLOWED_NODES = {
        ast.Module, ast.Expr, ast.Assign, ast.BinOp, ast.UnaryOp,
        ast.Num, ast.Constant, ast.Name, ast.Load, ast.Store,
        ast.Call, ast.If, ast.For, ast.Compare,
        ast.Add, ast.Sub, ast.Mult, ast.Div, ast.Pow, ast.Mod,
        ast.Eq, ast.NotEq, ast.Lt, ast.LtE, ast.Gt, ast.GtE,
        ast.List, ast.Tuple, ast.NameConstant
    }
    ALLOWED_NAMES = {
        "range", "sum", "len", "min", "max", "abs", "pow",
        "sin", "cos", "tan", "sqrt", "log", "exp", "floor", "ceil", "pi", "e", "tau", "send"
    }

    def __init__(self):
        self.globals = {
            "range": range, "sum": sum, "len": len,
            "min": min, "max": max, "abs": abs, "pow": pow,
            "sin": math.sin, "cos": math.cos, "tan": math.tan,
            "sqrt": math.sqrt, "log": math.log, "exp": math.exp,
            "floor": math.floor, "ceil": math.ceil,
            "pi": math.pi, "e": math.e, "tau": math.tau,
            "send": self.send_message,
            "__builtins__": {}
        }
        self.mailbox_out = {}

    def send_message(self, addr: int, code: str):
        self.mailbox_out = {"addr": addr, "opcode": "SET_CODE", "code": code}

    def check_node(self, node):
        if type(node) not in self.ALLOWED_NODES:
            raise ValueError(f"Unsupported node: {type(node).__name__}")
        if isinstance(node, ast.Name) and node.id not in self.ALLOWED_NAMES:
            raise ValueError(f"Unsupported name: {node.id}")
        for child in ast.walk(node):
            if type(child) not in self.ALLOWED_NODES:
                raise ValueError(f"Unsupported child node: {type(child).__name__}")
        return True

    def eval(self, code: List[str]) -> str:
        import signal
        def timeout_handler(signum, frame):
            raise TimeoutError("Evaluation timed out")
        signal.signal(signal.SIGALRM, timeout_handler)
        signal.alarm(1)
        code_str = "\n".join(code)
        try:
            tree = ast.parse(code_str, mode="exec")
            self.check_node(tree)
            loc: Dict[str, object] = {}
            exec(compile(tree, "<vpy>", "exec"), self.globals, loc)
            try:
                last_expr = ast.parse(code[-1], mode="eval")
                self.check_node(last_expr)
                result = eval(compile(last_expr, "<vpy>", "eval"), self.globals, loc)
                signal.alarm(0)
                return str(result)[:COLS-5]
            except SyntaxError:
                signal.alarm(0)
                return ""
        except Exception as e:
            signal.alarm(0)
            return f"Err: {str(e)[:COLS-5]}"

class Router:
    def __init__(self):
        self.stacks = {}  # {addr: (program, state)}

    def add_stack(self, addr: int, program, state: VPState):
        self.stacks[addr] = (program, state)

    def process_mailboxes(self):
        for addr, (program, state) in self.stacks.items():
            ctrl = decode(program._px, state)
            if ctrl["MAILBOX_OUT"]:
                msg = json.loads(ctrl["MAILBOX_OUT"])
                target_addr = msg["addr"]
                if target_addr in self.stacks:
                    target_program, target_state = self.stacks[target_addr]
                    if msg["opcode"] == "SET_CODE":
                        target_state.source_lines = msg["code"].split("\n")

def draw_pane(px: Px, x: int, y: int, lines: List[str], color_fg="#FFFFFF", color_bg="#1E2330", caret=None, blink=False):
    for r, line in enumerate(lines[:ROWS]):
        fg = "#FFD966" if line.strip().startswith(("if", "for")) else color_fg
        draw_text(px._draw, x, y + r * CELL_H, line.ljust(COLS)[:COLS], fg, color_bg)
    if caret and (not blink or (int(time.time() * 2) % 2)):
        cx, cy = x + caret[1] * CELL_W, y + caret[0] * CELL_H
        px.rect(cx, cy + CELL_H - 2, CELL_W, 2, "#00FF00")

def decode_pane(img: Image.Image, x: int, y: int, line_count: int) -> List[str]:
    return [sample_text(img, x, y + r * CELL_H).rstrip() for r in range(min(line_count, ROWS))]

def draw_heatmap(px: Px, x: int, y: int, truth: List[str], decoded: List[str]) -> List[List[Tuple[int, str, str]]]:
    mismatches = []
    max_rows = max(len(truth), len(decoded))
    for r in range(max_rows):
        t = (truth[r] if r < len(truth) else "").ljust(COLS)
        d = (decoded[r] if r < len(decoded) else "").ljust(COLS)
        row_mismatches = []
        for c in range(COLS):
            cx, cy = x + c * CELL_W, y + r * CELL_H
            color = "#002200" if t[c] == d[c] else "#220000"
            px.rect(cx, cy, CELL_W, CELL_H, color)
            if t[c] != d[c]:
                row_mismatches.append((c, t[c], d[c]))
        mismatches.append(row_mismatches)
    return mismatches

def draw_frame(px: Px, st: VPState):
    px.clear("#0E0F14")
    ax, ay = GAP, CTRL_H + GAP
    bx, by = ax + PANE_W + GAP, ay
    cx, cy = ax, ay + PANE_H + GAP
    dx, dy = bx, cy
    px.text(ax, ay-12, "A: Source (edit)", 12, "#A0FFA0")
    px.text(bx, by-12, "B: Pixelated (decoded)", 12, "#9BB4FF")
    px.text(cx, cy-12, "C: Result", 12, "#FFD966")
    px.text(dx, dy-12, "D: Decode Heatmap", 12, "#FF8080")
    draw_pane(px, ax, ay, st.source_lines, color_fg="#FFFFFF", color_bg="#1A1F2B", caret=st.caret, blink=True)
    draw_pane(px, bx, by, st.source_lines, color_fg="#FFFFFF", color_bg="#1E2330")
    draw_pane(px, cx, cy, [st.last_result], color_fg="#FFD966" if "Err" not in st.last_result else "#FF8080", color_bg="#1A1F2B")
    draw_control(px._draw, {
        "SCREEN_ID": 100,
        "PC": st.pc,
        "ADDR": PANE_ADDR,
        "SEQ": st.seq,
        "MAILBOX_IN": 0,
        "MAILBOX_OUT": json.dumps(st.mailbox_out) if st.mailbox_out else 0
    })

def decode(px: Px, st: VPState) -> Dict:
    img = px._img
    ctrl = read_control(img)
    if not ctrl.get("_crc_ok", False):
        ctrl["err"] = "crc"
    decoded_lines = decode_pane(img, bx, by, len(st.source_lines)) if PIXEL_READ else st.source_lines
    ctrl["code"] = "\n".join(decoded_lines)
    ctrl["_decoded_lines"] = decoded_lines
    return ctrl

def add_noise(img: Image.Image) -> Image.Image:
    img = img.filter(ImageFilter.GaussianBlur(radius=0.5))
    img = img.point(lambda p: min(255, max(0, p + int((random.random() - 0.5) * 10))))
    return img

def majority_vote(history: List[List[str]]) -> List[str]:
    if not history: return []
    result = []
    for row in range(max(len(frame) for frame in history)):
        votes = defaultdict(str)
        for frame in history:
            if row < len(frame):
                for col in range(COLS):
                    votes[(row, col)] += frame[row][col]
        result.append("".join(max(votes[(row, col)], key=len) for col in range(COLS)))
    return result

class HallOfDrift:
    def __init__(self, log_dir=FRAME_DIR):
        self.log_dir = log_dir
        os.makedirs(log_dir, exist_ok=True)

    def log_frame(self, st: VPState, ctrl: Dict, frame_idx: int, img: Image.Image, mismatches: List[List[Tuple[int, str, str]]], overlays: bool):
        mismatch_map = ["".join("x" if any(c[0] == col for c in row) else "." for col in range(COLS)) for row in mismatches]
        log = {
            "frame": frame_idx,
            "pc": st.pc,
            "source": st.source_lines,
            "decoded": ctrl.get("_decoded_lines", []),
            "result": st.last_result,
            "crc_ok": ctrl.get("_crc_ok", False),
            "mismatches": [
                [{"col": col, "expected": exp, "actual": act} for col, exp, act in row]
                for row in mismatches
            ],
            "mismatch_map": mismatch_map
        }
        log_path = f"{self.log_dir}/log_{frame_idx:06d}.json"
        with open(log_path, "w") as f:
            json.dump(log, f, indent=2)
        with open(f"{self.log_dir}/index.jsonl", "a") as f:
            json.dump({"frame": frame_idx, "pc": st.pc, "crc_ok": log["crc_ok"], "mismatch_count": sum(len(row) for row in mismatches)}, f)
            f.write("\n")
        if (any(mismatches) or not ctrl.get("_crc_ok", True)) and overlays:
            img.save(f"{self.log_dir}/fail_{frame_idx:06d}.png")
            with open(f"{self.log_dir}/fail_{frame_idx:06d}.json", "w") as f:
                json.dump({"error": "decode or CRC failure", **log}, f, indent=2)

class DriftDashboard:
    def __init__(self, log_dir=FRAME_DIR):
        self.root = tk.Tk()
        self.root.title("Hall of Drift")
        self.log_dir = log_dir
        self.logs = sorted(glob.glob(f"{log_dir}/log_*.json"))
        self.current = 0
        self.canvas = tk.Canvas(self.root, width=W, height=H)
        self.canvas.pack()
        self.info_label = tk.Label(self.root, font=("Consolas", 10), wraplength=W-20)
        self.info_label.pack()
        tk.Button(self.root, text="Prev", command=self.prev).pack(side="left")
        tk.Button(self.root, text="Next", command=self.next).pack(side="right")
        tk.Button(self.root, text="First Failure", command=self.first_failure).pack(side="left")
        self.load_frame()

    def load_frame(self):
        if not self.logs: return
        with open(self.logs[self.current]) as f:
            log = json.load(f)
        img_path = f"{self.log_dir}/fail_{log['frame']:06d}.png" if os.path.exists(f"{self.log_dir}/fail_{log['frame']:06d}.png") else f"{self.log_dir}/log_{log['frame']:06d}.png"
        self.photo = ImageTk.PhotoImage(Image.open(img_path))
        self.canvas.create_image(0, 0, image=self.photo, anchor="nw")
        mismatches = sum(len(row) for row in log["mismatches"])
        self.info_label.config(text=f"Frame {log['frame']} | PC: {log['pc']} | CRC OK: {log['crc_ok']} | Mismatches: {mismatches}\nSource: {log['source']}\nDecoded: {log['decoded']}\nResult: {log['result']}")

    def prev(self):
        self.current = max(0, self.current - 1)
        self.load_frame()

    def next(self):
        self.current = min(len(self.logs) - 1, self.current + 1)
        self.load_frame()

    def first_failure(self):
        for i, log_path in enumerate(self.logs):
            with open(log_path) as f:
                log = json.load(f)
            if any(log["mismatches"]) or not log["crc_ok"]:
                self.current = i
                self.load_frame()
                break

    def run(self):
        self.root.mainloop()

def run_visual_python_mvp(frames=90, out_dir=FRAME_DIR, live=True, overlays=True):
    root = tk.Tk()
    if not live:
        root.withdraw()
    else:
        canvas = tk.Canvas(root, width=W, height=H, bg="#0E0F14")
        canvas.pack()
        root.title("Visual Python MVP")

    px = Px(W, H, 60, out_dir if frames else None)
    st = VPState(source_lines=["x = 5", "sum(range(x))"], caret=(0, 0))
    evaluator = SafeEvaluator()
    editor = Editor(root, st)
    hall = HallOfDrift(out_dir)
    router = Router()
    router.add_stack(PANE_ADDR, px, st)
    decode_history = []

    code_changes = {
        40: ["y = 10", "sum(range(y))"],
        80: ["z = 3", "send(2, 'sum(range(5))')"]
    }

    if frames:
        for f in range(frames):
            if f in code_changes:
                st.source_lines = code_changes[f]
                st.caret = (0, len(st.source_lines[0]))
            draw_frame(px, st)
            px.tick()
            img = add_noise(px._img) if PIXEL_READ else px._img
            ctrl = decode(px, st)
            decode_history.append(ctrl["_decoded_lines"])
            decode_history = decode_history[-3:]  # 3-frame buffer
            ctrl["_decoded_lines"] = majority_vote(decode_history)
            assert ctrl.get("SCREEN_ID") == 100 and ctrl.get("_crc_ok", True), f"Frame {f} failed: {ctrl}"
            mismatches = [] if not PIXEL_READ else draw_heatmap(px, bx, by, st.source_lines, ctrl["_decoded_lines"])
            st = update(st, ctrl, evaluator)
            router.process_mailboxes()
            hall.log_frame(st, ctrl, f, px._img, mismatches, overlays)
            st.seq = (st.seq + 1) % 2
    else:
        photo = None
        last_seq = -1
        def loop():
            nonlocal photo, last_seq
            draw_frame(px, st)
            px.tick()
            img = add_noise(px._img) if PIXEL_READ else px._img
            ctrl = decode(px, st)
            if ctrl.get("SEQ", -1) != last_seq:  # Process only on new frame
                decode_history.append(ctrl["_decoded_lines"])
                decode_history = decode_history[-3:]
                ctrl["_decoded_lines"] = majority_vote(decode_history)
                mismatches = [] if not PIXEL_READ else draw_heatmap(px, bx, by, st.source_lines, ctrl["_decoded_lines"])
                st = update(st, ctrl, evaluator)
                router.process_mailboxes()
                hall.log_frame(st, ctrl, st.pc, px._img, mismatches, overlays)
                last_seq = ctrl.get("SEQ", -1)
                st.seq = (st.seq + 1) % 2
            photo = ImageTk.PhotoImage(px._img)
            canvas.create_image(0, 0, image=photo, anchor="nw")
            root.after(16, loop)
        loop()
        root.mainloop()

## Addressing Refresh Rate Integration
- **Vsync Synchronization**: The loop uses `root.after(16, loop)` to approximate 60Hz, aligning with the screen’s refresh. In live mode, updates are gated by the `SEQ` bit to ensure frame coherence.
- **State Change Logic**: Changes (e.g., new code, mailbox messages) are applied only after decoding and verifying the previous frame, ensuring causality:
  ```python
  if ctrl.get("SEQ", -1) != last_seq:
      # Process new frame: decode, execute, update state
      st = update(st, ctrl, evaluator)
  ```
- **Temporal ECC**: The `majority_vote` function reduces transient errors, critical for analog stability.
- **Future Vsync**: For hardware, use `DXGIWaitForVBlank` (Windows) or `CVDisplayLink` (macOS) to lock to the actual refresh rate.

---

## Addressing Critiques
- **Pixel-to-Code Fragility**: Mitigated by grid font, CRC, and majority voting. Noise injection tests will further harden the system.
- **Security**: AST-based executor ensures no unsafe operations. `restrictedpython` can be added for production.
- **Performance**: Loop stays under 16ms; heatmap and majority voting are optimized for real-time.
- **Hybrid Alternative**: The current design tests the full pixel-based execution path, but a memory-based fallback can be implemented if analog decoding fails stress tests.

def temporal_majority_vote(frames_buffer):
    """
    Use multiple frames to correct errors via majority voting
    frames_buffer: list of last N decoded frames
    """
    if len(frames_buffer) < 3:
        return frames_buffer[-1] if frames_buffer else None
    
    # For each character position, take the majority value
    result = []
    for char_pos in range(len(frames_buffer[0])):
        chars_at_pos = [frame[char_pos] for frame in frames_buffer]
        # Count occurrences and take most common
        from collections import Counter
        most_common = Counter(chars_at_pos).most_common(1)
        result.append(most_common[0][0] if most_common else ' ')
    
    return ''.join(result)

The fundamental idea is to synchronize the central program loop with the display's refresh cycle. Here is how we can use the screen refresh to drive the system and change what's on the screen:

### 1. The Vsync-Driven Main Loop
The central processing ritual of the visual computer operates in a continuous cycle, driven by the display's vertical synchronization (Vsync). This ensures that a new frame is processed and rendered for every screen update, preventing visual artifacts like screen tearing. The loop works like this [1]:
1.  **Wait for Refresh**: The program blocks until the display hardware is ready for a new frame (the vertical blanking interval).
2.  **Capture and Decode**: The system "looks" at what was just presented on the screen and captures it. It then decodes the machine-readable information from the control strip and the content panes.
3.  **Execute Logic**: The decoded information (e.g., the program code, mailbox messages) is processed. The program state is updated based on the execution result.
4.  **Render Next Frame**: Based on the new state, the system renders the next frame, including the updated code, results, and control strip.
5.  **Present Frame**: The rendered frame is placed into a buffer, ready to be displayed on the next refresh cycle.

This one-frame delay between presenting a frame and acting on its contents is a critical "causal guardrail" that keeps the system stable.[1]

### 2. The Control Strip as a Communication Bus
To make this loop robust and reliable, the machine-readable control strip is essential. We can use it to encode temporal and state information that the computer needs to process the next frame correctly.[1]
-   **Sequence Bit (SEQ)**: A single bit in the control strip can be toggled on each frame. The computer only acts on a frame when this bit changes, preventing it from double-processing the same frame.
-   **Two-Phase Commit**: A robust method is to dedicate one frame to displaying a new command and the next frame to decoding and verifying it. If the decoder confirms the command's integrity (e.g., via a CRC checksum), the system commits the changes. If there's a mismatch, it can highlight the error and ignore the command, preventing a pixel glitch from corrupting the program state.

### 3. Using the Refresh Rate for Synchronization and Resilience
This refresh-driven approach is invaluable for both the digital and analog phases of your project.[1]
-   **Digital**: It provides a stable clock for the software simulation, ensuring that all tests are deterministic and reproducible. It allows you to precisely budget the time for each step of your loop (e.g., decoding and execution must fit within a 16ms window for a 60Hz display).
-   **Analog**: For a physical camera and monitor, this pattern allows you to phase-lock the camera's capture to the monitor's output, preventing tearing and motion blur. By adding a small, dedicated metronome patch to the screen, the camera can measure the frame boundaries and correct for rolling shutter effects. You can also use specific "calibration frames" to adjust the camera's settings (e.g., gamma, alignment) on the fly without interrupting the main program loop.

In essence, the screen's refresh rate becomes the central authority for timing. You use it to tell your program "it's time to act," rather than relying on an arbitrary timer or polling loop. This creates a clean, testable, and robust architecture that scales from a single-pane digital MVP to a multi-screen analog computer.[1]
